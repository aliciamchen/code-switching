# Varied audience (Experiment 4)

This experiment tests how participants choose between earlier and later labels as the composition of their audience varies, given a referential or social-identification goal. This folder contains the jsPsych experiment code and stimuli. Note that this experiment's folder is named with a hyphen (`experiments/varied-audience`), while the analysis and data folders use an underscore (`analysis/varied_audience`, `data/varied_audience`).

The "unseen" tangram labels (used in manipulation-check trials) are taken from the other group color for the shared-label tangrams, and from the other counterbalancing assignment for the group-specific-label tangrams.
